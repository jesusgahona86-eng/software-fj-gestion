# Software FJ – Sistema Integral de Gestión de Clientes, Servicios y Reservas

## Descripción del proyecto

Proyecto desarrollado para la Fase 4 – Prácticas simuladas del curso Programación, código 213023, de la Universidad Nacional Abierta y a Distancia (UNAD).

El sistema permite gestionar clientes, servicios y reservas mediante la programación orientada a objetos en Python, incorporando validaciones y manejo de excepciones para controlar los errores durante su ejecución.

## Funcionalidades

- Registro y gestión de clientes.
- Gestión de servicios.
- Creación y consulta de reservas.
- Confirmación y cancelación de reservas.
- Validación de datos.
- Manejo de excepciones personalizadas.
- Registro de eventos y errores.

## Archivos del proyecto

- main.py: código principal del sistema.
- logs.txt: registro de eventos y errores generados durante la ejecución.
- README.md: documentación general del proyecto.
- .gitignore: configuración de archivos excluidos del control de versiones.

## Instrucciones de ejecución

1. Descargar el repositorio.
2. Extraer los archivos.
3. Abrir la carpeta del proyecto en Visual Studio Code.
4. Tener Python 3 instalado.
5. Abrir la terminal y ejecutar el comando:

`python main.py`

6. Consultar el archivo logs.txt para revisar los eventos y errores registrados.

## Modalidad de desarrollo

El proyecto se desarrolló de manera individual debido a las dificultades de comunicación con los integrantes del grupo y de acceso al repositorio grupal.
